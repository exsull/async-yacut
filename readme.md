# Проект YaCut

Проект YaCut — это сервис укорачивания ссылок. Его назначение —   
ассоциировать длинную пользовательскую ссылку с короткой, которую   
предлагает сам пользователь или предоставляет сервис.   

Дополнительная функция YaCut — загрузка сразу нескольких файлов на Яндекс Диск   
и предоставление коротких ссылок пользователю для скачивания этих файлов.

## Возможности

- генерация коротких ссылок и их связь с исходными длинными ссылками;
- асинхронная загрузка файлов на Яндекс Диск с собственной генерацией коротких ссылок для каждого файла;
- переадресация на исходный адрес или скачивание файлов при обращении к коротким ссылкам;

### Как запустить проект Yacut:

Клонировать репозиторий и перейти в него в командной строке:

```bash
git clone git@github.com:exsull/async-yacut.git
cd yacut
```

Cоздать и активировать виртуальное окружение:

```bash
python3 -m venv venv
```

* Если у вас Linux/macOS

    ```bash
    source venv/bin/activate
    ```

* Если у вас windows

    ```bash
    source venv/scripts/activate
    ```

Установить зависимости из файла requirements.txt:

```bash
python3 -m pip install --upgrade pip
```

```bash
pip install -r requirements.txt
```

Создать в директории проекта файл `.env`.  
Скопировать `.env.example` в `.env` и заполнить значения переменных окружения.  

```python
FLASK_APP=yacut
FLASK_ENV=development
SECRET_KEY=your_secret_key
DATABASE_URI=sqlite:///db.sqlite3
DISK_TOKEN=y0__yoUr_T0k3N_3x4mPl3
```

Создать базу данных и применить миграции:

```bash
flask db upgrade
```

Запустить проект:

```bash
flask run
```
